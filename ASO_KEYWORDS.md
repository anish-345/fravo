# Fravo — Google Play ASO Keyword Research

**Date:** 2026-08-12 · **Target:** Google Play Store (Android) · **Goal:** Traffic + category positioning for Shipaton

---

## 0. Market reality check (read this first)

The "walk to earn screen time" space is **no longer empty**. Competitors already shipping:

| App | Platform | Position / Copy angle | Size signal |
|---|---|---|---|
| **Stroll – Steps to Screen Time** | Google Play | "gentle app blocker", step counter + 30s usage tracking, Health Connect | ~500+ downloads |
| **WalkMyScreen** | Web/Android | "Earn Screen Time by Walking", 1,000 steps = minutes, hard-ish block screen | Unknown |
| **Steppin** | iOS | Built by Kayak co-founder **Paul English** — big press (Business Insider), planned ~$20/yr subscription | Waitlist for Android |
| **Skrid** | iOS | Steps → coins → minutes economy, blocks after daily limit | New |
| **Walk To Scroll** | iOS | "Earn Screen Time with Steps", per-app quotas, 2am reset | New |
| **CashWalk / WalkEarn** | Google Play | Walk → **cash** (NOT screen time) | Different intent — ignore |

### What this means for you

1. **The concept is validated** — a Kayak co-founder betting on it is strong third-party proof. Good for your Shipaton story too.
2. **The category is still young enough to win.** Stroll is at ~500 downloads. Nobody owns the search terms yet.
3. **Your real differentiator is HARD blocking.** Stroll's own copy says "gentle... without harsh blocking" — Fravo actually locks the app with a block-screen overlay. That's the wedge. Lead with "**Actually blocks it**" positioning.
4. Do **not** target "walk to earn money" / "earn money walking" keywords — that pulls CashWalk-type traffic (reward-app users who want cash), wrong users, wrong monetization, misleading.

## 1. Keyword tiers

### 🥇 Tier 1 — Differentiator keywords (WIN HERE first)

Medium intent, low competition, **nobody owns them yet**. These are your first-week targets.

| Keyword | Why | Where to place |
|---|---|---|
| walk to earn screen time | Exact category phrase Steppin/WalkMyScreen built around; growing search interest | Title, short desc, first paragraph |
| earn screen time | Shorter variant of the same intent | Title, description ×3 |
| steps to screen time | Stroll's exact title phrase — proven pull | Title candidate, description |
| walk to unlock apps | Action-phrased variant used by Stroll/Skrid copy | Description ×2 |
| screen time rewards | Monetization-adjacent phrasing, low competition | Description |
| earn screen time by walking | WalkMyScreen's exact phrasing | Description |

### 🥈 Tier 2 — Category head terms (high volume, brutal competition)

Dominated by AppBlock (200K reviews), Freedom, StayFree, One Sec, Forest, Digital Wellbeing. **Don't expect to rank in week 1** — these matter as you grow.

| Keyword | Competition reality |
|---|---|
| app blocker | AppBlock owns it; long shot early |
| screen time app / screen time tracker | Crowded; build up to it |
| social media blocker | Medium; winnable later |
| block apps / stop apps | Long-tail fragments worth scattering in copy |

### 🥉 Tier 3 — Pain / intent long-tail (highest conversion)

People searching these have the problem *and* are ready to try a solution:

- stop doomscrolling
- reduce screen time
- limit screen time
- less screen time
- phone addiction
- digital detox
- block instagram / block tiktok / block youtube / block social media
- quit social media
- screen time limit app

> ⚠️ **Trademark caution:** naming "Instagram / TikTok / YouTube" in copy is standard in this category (Stroll does it), and it converts — but use them sparingly (once or twice), never in the title, and keep the phrasing "block Instagram, TikTok, YouTube & more" rather than claiming affiliation.

### 4th tier — Audience wording (supporting, not primary)

- digital wellbeing
- focus app
- step counter (careful — owned by fitness apps; only in description)
- walking reward app
- healthy phone habits

## 2. Title strategy (max 30 characters)

Every word in the title carries the most ranking weight. Trade-off: lead with the **differentiator** (category is young, phrase is huntable) vs the **head term** (app blocker).

**Primary recommendation (30 chars exactly):**
```
Fravo Walk to Earn Screen Time
```
*Rationale:* packs brand + the exact category phrase + highest-intent words. This is the phrase Steppin/WalkMyScreen/Stroll all orbit, and none own the exact string on Play.

**Alternatives (A/B test later):**
```
Fravo - Walk to Earn Screen Time   (31 — one over, use "Fravo Walk"?)
Fravo Walk to Earn Screen Time!
Fravo: Walk to Earn Screen Time   (32 — over limit)
```
When you have installs + Play Console data, test a variant swapping in "App Blocker": e.g. `Fravo Walk to Earn Screen Time` → `Fravo Screen Time App Blocker` and compare.

## 4. Full description — keyword placement map

Order matters. First 2 sentences are the most weighted — put Tier 1 keywords there. Repeat Tier 1 terms naturally 2–3× later, never keyword-stuff.

**Draft opening (first 3 sentences):**
> Fravo turns your daily steps into screen time you actually feel — **walk to earn screen time** instead of staring at a timer. Walk 1,000 steps and **earn screen time** on the apps you love: **block Instagram, TikTok, YouTube & more** when the time runs out. Built as a real **app blocker** for Android with **digital wellbeing** at its core — no banning, no guilt, just **earn your minutes**.

**Keyword density map for the body:**

| Section | Keywords to weave in naturally |
|---|---|
| "Why Fravo" | earn screen time, walk to earn, stop doomscrolling, phone addiction |
| "How it works" (1-2-3) | 1,000 steps, minutes, block apps, app blocker |
| "Your apps" | block instagram, block tiktok, block youtube, social media blocker, 15 presets |
| "Step tracking" | step counter, Health Connect, pedometer |
| "Free vs Pro" | screen time app, screen time rewards, unlimited apps, custom rates |
| "Privacy" | on-device, no account, no ads → supports Peace Prize narrative |
| Keywords overall | **screen time** (4–6×), **walk to earn screen time/earn screen time** (3–4×), **app blocker** (2–3×), **doomscroll** (1–2×), **digital wellbeing/detox** (2×), app names (1–2×) |

**Anti-patterns (Google penalizes):** repeating the same keyword 5+× (stuffing), keyword walls, trademark over-use, claiming #1/best without basis, targeting "earn money walking" (wrong intent).

## 5. 30-day plan

1. **Week 1:** Ship with recommended title + short desc + opening paragraph (the three highest-weight slots).
2. **Weeks 2–4:** In Play Console → Acquisition reports, watch which search terms actually bring impressions. Google gives you the real query data free — rank for what it says, not what you guessed.
3. **Every 7 days max:** if impressions on Tier 1 terms are flat, swap one title word (e.g. add "Blocker", drop "Walk"). Title is the cheapest A/B you can run.
4. **Track:** installs attributed to "walk to earn screen time" cluster — that's your moat metric. If it moves, you own the category.
