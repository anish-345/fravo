## 📌 Overview

Effective project execution and academic management require structured time accountability. The **Fully Embedded Cross-Tick Tracker** is an interactive spreadsheet system engineered with dynamic validation rules, automated status switches, and visual milestone dashboards to optimize personal productivity and project timelines.

---

## 🚀 Key Features

- ✅ **Interactive Cross-Tick Verification**: Automated status checkboxes/switches that update task completion states dynamically.
- 📊 **Real-Time Progress Tracking**: Calculates overall completion percentages and category-wise productivity metrics automatically.
- 🕒 **Time Allocation & Scheduling**: Visual layout for tracking estimated vs. actual time spent across tasks.
- 🎨 **Smart Conditional Formatting**: Color-coded task priorities, overdue warnings, and completed milestones for quick visual scanning.
- 📈 **Zero-Macro Compatibility**: Built entirely with robust native Excel formulas for universal cross-platform compatibility (Excel Desktop, Office 365, Google Sheets).

## 🛠️ How to Use

1. **Download the Workbook**:
   - Clone this repository or download [`Fully_Embedded_Cross_Tick_Tracker-Piyushdewangan.xlsx`](./Fully_Embedded_Cross_Tick_Tracker-Piyushdewangan.xlsx) directly.
2. **Open in Excel / Google Sheets**:
   - Compatible with Microsoft Excel 2016+, Office 365, and Google Sheets.
3. **Input Tasks & Schedules**:
   - Define your task milestones, deadlines, and allocated hours.
   - Use the built-in tick validation to update task states in real time.
